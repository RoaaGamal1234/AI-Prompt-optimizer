# 📖 Project Overview

AI Prompt Optimizer** is an intelligent tool designed to transform simple user input prompts into well-structured, professional, and context-aware prompts. By utilizing Prompt Engineering principles and Output Parsers, the application enhances LLM generation quality by automatically injecting roles, background context, strict constraints, and formatted expected outputs.

---

# ✨ Features

* **Prompt Enhancement:** Automatically rewrites basic, ambiguous prompts into clear and detailed instructions.
* **Structured Output Parsing:** Extracts and formats prompt components into defined elements:
  * **Improved Prompt:** The optimized version of the input.
  * **Role:** Assigns a specific persona/role to the model.
  * **Context:** Adds relevant background information.
  * **Constraints:** Defines guidelines, rules, and boundaries.
  * **Expected Output:** Specifies the exact output format desired.
* **Interactive Interface:** Easy-to-use interface built using Streamlit / Python.
